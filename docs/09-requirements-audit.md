# 原依頼との要件差分

2026-10-25。最初の依頼を全件実装したとする以前の完了報告は不正確だった。最新の方針「認証なし・単にSSG」に従う範囲と、実装していない機能を区別する。

| 原依頼 | 現状 |
| --- | --- |
| Astro / TypeScript / 単一アプリ / Vite | 実装。Astroの静的生成。 |
| Void / Cloudflare | Void CLIの静的ディレクトリ公開を使用。Astro SSR adapterは使用しない。公開結果は10-deployment.mdに記録する。 |
| DevboxでNode/pnpm固定 | 実装。実行パス・frozen-lockfile・check/test/buildをDevbox内で検証。 |
| 記事一覧・詳細・日付・本文・出典・RSS・空状態 | 実装。公開Markdownだけを静的生成。 |
| 下書き保存・公開・非公開化 | Markdownのdraftで運用。反映には再ビルドと公開が必要。管理画面からの操作は未実装。 |
| 認証・管理画面 | 追加指示で対象外。実装していない。 |
| D1 / Drizzle / SQL migration / 保存後再ビルド不要 | SSGへの変更で未実装。Markdown保存。再ビルドが必要。 |
| R2画像管理・アップロード・DB関連 | 最新AGENTS.mdで再導入しない方針。未実装。許諾済み画像を原稿と静的資産で管理。 |
| 外部RSS収集・重複排除・Cron | 最新AGENTS.mdでCronを再導入しない方針。未実装。出典の手作業記入。 |
| 9章UIルール | 05に全ルールを対応付け。実コードと画面の確認結果は08。非該当・未検証を合格扱いしない。 |
| レスポンシブ・キーボード・フォーカス・コントラスト | 実画面の限定範囲で検証。包括的な支援技術監査は未実施。 |
| 秘密情報・権利不明画像・架空記事の禁止 | 公開用原稿は0件。検証記事は分離。秘密情報は公開対象に含めない。 |
| docs / README / AGENTS | 実装に合わせて更新。 |
| push / 本番デプロイ禁止 | 今回の明示依頼により、この作業のpushとSSGデプロイを許可。未許可の本番操作は引き続き禁止。 |

「元の全機能を完璧に実装済み」とは報告しない。SSGとしての公開範囲と省略範囲をこの表で明示する。
